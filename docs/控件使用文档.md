# gofluent 控件使用文档

> gofluent 是 PyQt-Fluent-Widgets 的 Go + miqt（Qt5）移植。组件库位于 `gofluent/components/`，按功能分为 6 个包：`widgets`、`navigation`、`dialog_box`、`settings`、`date_time`、`layout`。本文档详细介绍每个控件的**功能、参数、调用方法与效果**。

## 目录

1. [widgets 包](#一widgets-包)—— 按钮、卡片、输入框、列表、菜单、进度、滚动、标签页、表格、树、气泡提示等
2. [navigation 包](#二navigation-包)—— 导航面板、面包屑、Pivot、分段控件等
3. [dialog_box 包](#三dialog_box-包)—— 消息对话框、遮罩对话框、颜色选择、文件夹列表等
4. [settings 包](#四settings-包)—— 设置卡片系列
5. [date_time 包](#五date_time-包)—— 日期 / 时间 / 日历选择器
6. [layout 包](#六layout-包)—— 流式布局、垂直布局、展开布局

## 通用约定

- 每个控件都内嵌一个 `*qt.QWidget`（字段名 `QWidget`），通过 `.QWidget` 放入布局或作为父容器，例如 `layout.AddWidget(btn.QWidget)`。
- `parent *qt.QWidget` 表示父控件，几乎所有构造函数的最后一个参数都是它，可传 `nil`。
- `icon interface{}` 图标源参数可传 `*qt.QIcon`、字符串路径、`common.FluentIconBase`（如 `common.Folder`），或 `nil`。
- 回调通常以「字段」形式暴露（如 `OnClicked func()`），直接赋值即可；也保留 Qt 风格的信号方法（如 `OnClicked(func)`）。

# 一、widgets 包

## button.go

### `PushButton`
- **功能**：Fluent 风格普通按钮，用于触发一次点击操作。
- **构造**：
  - `NewPushButton(parent *qt.QWidget)` / `NewPushButtonText(text string, parent *qt.QWidget)` / `NewPushButtonIcon(icon interface{}, text string, parent *qt.QWidget)`
  - `icon`：图标源；`text`：按钮文本；`parent`：父控件。
- **关键方法**：`SetIcon(icon interface{})`、`Icon()/GetIcon() *qt.QIcon`；继承 `QPushButton` 的 `SetText`、`OnClicked(func())`、`SetIconSize(*qt.QSize)`、`SetEnabled`、`SetCheckable`、`SetChecked` 等。
- **调用示例**：
  ```go
  btn := widgets.NewPushButtonIcon(common.Accept, "确定", parent)
  btn.SetIconSize(qt.NewQSize2(16, 16))
  btn.OnClicked(func() { /* 处理点击 */ })
  ```
- **效果**：带主题色边框/背景、悬停与按下态反馈的圆角按钮，图标绘制在文本左侧。

### `PrimaryPushButton`
- **功能**：主色（强调色）填充按钮，用于突出主要操作。
- **构造**：`NewPrimaryPushButton(parent)` / `NewPrimaryPushButtonText(text, parent)` / `NewPrimaryPushButtonIcon(icon, text, parent)`。
- **关键方法**：继承 `PushButton`。
- **效果**：按钮主体填充主题主色，图标/文字反色，悬停/按下有亮度变化。

### `TransparentPushButton`
- **功能**：透明背景按钮，适合工具栏或悬停才显示边框的场景。
- **构造**：`NewTransparentPushButton(parent)` / `...Text(text, parent)` / `...Icon(icon, text, parent)`。
- **效果**：默认无背景，悬停/按下时才显示淡色背景。

### `ToggleButton`
- **功能**：可切换（复选）状态的按钮，用于开/关型选项。
- **构造**：`NewToggleButton(parent)` / `...Text(text, parent)` / `...Icon(icon, text, parent)`。
- **关键方法**：继承 `PushButton`；`SetChecked(bool)` / `IsChecked() bool`。
- **效果**：点击在选中/未选中之间切换，选中时呈高亮主题色。

### `TransparentTogglePushButton`
- **功能**：透明背景的可切换按钮。
- **构造**：`NewTransparentTogglePushButton(parent)` / `...Text(text, parent)` / `...Icon(icon, text, parent)`。
- **效果**：透明背景，选中时高亮，用于命令栏/工具区。

### `HyperlinkButton`
- **功能**：外观如链接的按钮，点击用系统默认浏览器打开 URL。
- **构造**：`NewHyperlinkButton(parent)` / `NewHyperlinkButtonURL(url, text string, parent)` / `NewHyperlinkButtonIcon(icon interface{}, url, text string, parent)`。
- **关键方法**：`SetUrl(url string)` / `Url() *qt.QUrl`；继承 `PushButton`。
- **效果**：手型光标、主题色文字/图标，点击打开链接。

### `RadioButton`
- **功能**：Fluent 风格单选按钮，同一父容器内互斥选择。
- **构造**：`NewRadioButton(parent)` / `NewRadioButtonText(text string, parent)`。
- **关键方法**：`SetTextColor(light, dark *qt.QColor)`、`SetIndicatorColor(light, dark *qt.QColor)`；继承 `QRadioButton` 的 `SetChecked`、`IsChecked`、`OnToggled(func(bool))`、`OnClicked(func())`。
- **效果**：圆形指示器，悬停/按下/选中配色不同，选中时内部填充主题色。

### `ToolButton`
- **功能**：Fluent 风格工具按钮，仅显示图标（无文本），常用于工具栏。
- **构造**：`NewToolButton(parent)` / `NewToolButtonIcon(icon interface{}, parent)`。
- **关键方法**：`SetIcon(icon interface{})`、`Icon() *qt.QIcon`、`SetDrawIconFunc(func(icon interface{}, painter *qt.QPainter, rect *qt.QRectF))`；继承 `QToolButton` 的 `OnClicked` 等。
- **效果**：居中绘制的图标按钮，默认透明背景、悬停/按下有淡色反馈。

### `TransparentToolButton` / `PrimaryToolButton`
- **功能**：透明背景 / 主色填充的工具按钮。
- **构造**：`NewTransparentToolButton(parent)` / `NewPrimaryToolButton(parent)` 及 `...Icon(icon, parent)` 变体。
- **效果**：透明无背景 / 主色圆角背景 + 反色图标。

### `ToggleToolButton` / `TransparentToggleToolButton`
- **功能**：可切换（复选）状态的工具按钮。
- **构造**：`NewToggleToolButton(parent)` / `NewTransparentToggleToolButton(parent)` 及 `...Icon(icon, parent)` 变体。
- **关键方法**：继承 `ToolButton`；`SetChecked(bool)` / `IsChecked() bool`。
- **效果**：点击切换选中态，选中时图标反色、主色高亮。

### `DropDownPushButton`
- **功能**：带下拉箭头与弹出菜单的按钮，点击右侧箭头弹出菜单。
- **构造**：`NewDropDownPushButton(parent)` / `...Text(text, parent)` / `...Icon(icon, text, parent)`。
- **关键方法**：`SetMenu(menu *RoundMenu)` / `Menu() *RoundMenu`；继承 `PushButton`。
- **效果**：按钮右端有向下箭头，点击箭头先下压回弹再居中弹出菜单。

### `TransparentDropDownPushButton` / `PrimaryDropDownPushButton`
- **功能**：透明 / 主色背景的下拉按钮。
- **构造**：`NewTransparentDropDownPushButton(parent)` / `NewPrimaryDropDownPushButton(parent)` 及 `...Text` / `...Icon` 变体。

### `DropDownToolButton` / `TransparentDropDownToolButton` / `PrimaryDropDownToolButton`
- **功能**：带下拉箭头与菜单的工具按钮（普通 / 透明 / 主色）。
- **构造**：`NewDropDownToolButton(parent)` 等及 `...Icon(icon, parent)` 变体。
- **关键方法**：`SetMenu(menu *RoundMenu)` / `Menu() *RoundMenu`。

### `SplitPushButton`
- **功能**：「主按钮 + 右侧下拉箭头」组成的分裂按钮，主按钮触发主操作、箭头弹菜单/浮层。
- **构造**：`NewSplitPushButton(parent)` / `...Text(text, parent)` / `...Icon(icon, text, parent)`。
- **关键方法**：`OnClicked(f func())`、`OnDropDownClicked(f func())`、`SetFlyout(flyout interface{})`、`SetText/SetIcon/SetIconSize`、`SetDropIcon/SetDropIconSize`。
- **效果**：左侧主按钮 + 右侧窄箭头按钮，二者独立响应点击。

### `PrimarySplitPushButton`
- **功能**：主色填充的分裂按钮。
- **构造**：`NewPrimarySplitPushButton(parent)` 及 `...Text` / `...Icon` 变体。

### `SplitToolButton` / `PrimarySplitToolButton`
- **功能**：「图标主工具按钮 + 下拉箭头」组成的分裂工具按钮（普通 / 主色）。
- **构造**：`NewSplitToolButton(parent)` / `NewPrimarySplitToolButton(parent)` 及 `...Icon(icon, parent)` 变体。

### `PillPushButton` / `PillToolButton`
- **功能**：胶囊形（全圆角）可切换按钮 / 工具按钮。
- **构造**：`NewPillPushButton(parent)` / `NewPillToolButton(parent)` 及 `...Text` / `...Icon` 变体。
- **关键方法**：继承 `ToggleButton`（含 `SetChecked` / `IsChecked`）。
- **效果**：两侧完全圆角的胶囊外观，选中时主色填充。

## card_widget.go

### `CardWidget`
- **功能**：圆角卡片容器，带主题背景与悬停/按下反馈，可承载任意子控件。
- **构造**：`NewCardWidget(parent *qt.QWidget)`。
- **关键方法**：`OnClicked(f func())`、`SetClickEnabled(bool)` / `IsClickEnabled()`、`SetBorderRadius(int)` / `BorderRadius()`。
- **效果**：半透明白色圆角卡片，悬停变亮、按下变暗，可点击。

### `SimpleCardWidget`
- **功能**：平铺背景的卡片（悬停/按下与普通背景一致），适合静态面板。
- **构造**：`NewSimpleCardWidget(parent)`。
- **效果**：无交互态变化的圆角卡片，带细边框。

### `ElevatedCardWidget`
- **功能**：悬停时带投影的卡片（无位移动画）。
- **构造**：`NewElevatedCardWidget(parent)`。
- **效果**：鼠标悬停时卡片下方浮现柔和阴影。

### `CardSeparator`
- **功能**：卡片内使用的细分割线（3px 高）。
- **构造**：`NewCardSeparator(parent)`。

### `HeaderCardWidget`
- **功能**：带标题栏 + 分割线 + 内容区的卡片。
- **构造**：`NewHeaderCardWidget(parent)` / `NewHeaderCardWidgetTitle(title string, parent)`。
- **关键方法**：`SetTitle(string)` / `Title()`。
- **效果**：顶部加粗标题（15px），下方分割线与内容区，整体圆角。

### `CardGroupWidget`
- **功能**：分组卡片中的一行（图标 + 标题 + 副文本 + 可选控件）。
- **构造**：`NewCardGroupWidget(icon interface{}, title, content string, parent)`。
- **关键方法**：`SetTitle/Title`、`SetContent/Content`、`SetIcon/Icon`、`SetIconSize(*qt.QSize)`、`SetSeparatorVisible(bool)`、`AddWidget(widget, stretch int)`。
- **效果**：一行设置项，左图标、右侧标题+灰色副文本，可附控件与分割线。

### `GroupHeaderCardWidget`
- **功能**：可容纳多行 `CardGroupWidget` 的带标题分组卡片。
- **构造**：`NewGroupHeaderCardWidget(parent)`。
- **关键方法**：`AddGroup(icon, title, content, widget, stretch int) *CardGroupWidget`、`GroupCount()`、`SetTitle/Title`。
- **效果**：标题下纵向排列多个设置行，行间自动显示分割线。

## check_box.go

### `CheckBox`
- **功能**：Fluent 风格复选框，支持选中/半选（三态）显示。
- **构造**：`NewCheckBox(parent)` / `NewCheckBoxText(text string, parent)`。
- **关键方法**：`SetCheckedColor(light, dark *qt.QColor)`、`SetTextColor(light, dark *qt.QColor)`；继承 `QCheckBox` 的 `SetChecked`、`IsChecked`、`SetTristate`、`OnStateChanged(func(int))`、`OnToggled(func(bool))`。
- **效果**：方形指示器内绘制对勾（选中）或短横（半选），支持悬停/按下/禁用各态配色。

## combo_box.go

### `ComboBox`
- **功能**：Fluent 风格下拉选择框，基于按钮 + 弹出菜单实现。
- **构造**：`NewComboBox(parent *qt.QWidget)`。
- **关键方法**：
  - 增删：`AddItem(text string, icon interface{}, userData interface{})`、`AddItems([]string)`、`InsertItem(index, text, icon, userData)`、`RemoveItem(index)`、`Clear()`。
  - 选中：`CurrentIndex()/SetCurrentIndex`、`CurrentText()/SetCurrentText`、`CurrentData()`。
  - 条目：`ItemText/ItemData/ItemIcon`、`SetItemText/SetItemData/SetItemIcon/SetItemEnabled`、`FindText/FindData`、`Count()`。
  - 外观：`SetPlaceholderText(text)`、`SetMaxVisibleItems(num)`。
  - 信号：`OnCurrentIndexChanged(func(int))`、`OnCurrentTextChanged(func(string))`、`OnActivated`、`OnTextActivated`。
- **效果**：点击展开居中弹出的菜单，选择后按钮文本更新并触发回调；有占位文案态与下拉箭头动画。

### `EditableComboBox`
- **功能**：可编辑下拉框，基于 `LineEdit` 实现，允许手动输入并可回车新增条目。
- **构造**：`NewEditableComboBox(parent)`。
- **关键方法**：与 `ComboBox` 基本一致。
- **效果**：文本可编辑的输入框，右端带下拉箭头；输入内容回车后若不存在则自动追加为条目。

- **构造**：`NewCommandSeparator(parent)`。

### `CommandMenu`
- **功能**：命令栏「更多操作」按钮弹出的圆角菜单（条目高 32、图标 16×16）。

### `CommandViewMenu`

### `CommandBar`
- **功能**：横向命令按钮栏，空间不足时把溢出按钮收进「更多」菜单。
- **构造**：`NewCommandBar(parent)`。
- **关键方法**：`AddAction(*qt.QAction) *CommandButton`、`AddActions`、`AddHiddenAction`、`InsertAction`、`RemoveAction`、`AddWidget`、`AddSeparator`、`SetSpacing`、`SetToolButtonStyle`、`SetButtonTight`、`SetIconSize`、`SetFont`、`SetMenuDropDown`、`SuitableWidth()`、`ResizeToSuitableWidth()`。

### `CommandViewBar`
- **功能**：`CommandBarView` 内部使用的命令栏，其「更多」菜单附着于外层视图。
- **构造**：`NewCommandViewBar(parent)`，继承 `CommandBar`。

### `CommandBarView`
- **功能**：自绘圆角背景的命令栏容器，可嵌入 `Flyout` 弹出。
- **构造**：`NewCommandBarView(parent)`。

- **效果**：圆角浅/深色底 + 细边框的命令栏浮层，适合作为上下文工具条。

## cycle_list_widget.go

### `CycleListWidget`
- **功能**：带上下滚动按钮、居中选中行的循环滚动列表（多用于日期/时间选择器）。

- **效果**：居中高亮的滚动列表，条目超出可视区时重复以支持循环滚动，悬停显示上下箭头，滚动平滑动画。

# 六、layout 包

## flow_layout.go

### `FlowLayout`
- **功能**：流式布局，控件按从左到右顺序排列，超出可用宽度时自动换行，并支持布局重排动画。
- **构造**：`NewFlowLayout(parent *qt.QWidget, needAni, isTight bool)`。
  - `needAni`：是否在重排时为控件位置变化添加动画；`isTight`：紧凑模式（跳过隐藏控件）。
- **关键方法**：`AddWidget(w)`、`InsertWidget(index, w)`、`InsertItem(index, item)`、`AddItem(item)`、`RemoveWidget(w)`、`RemoveAllWidgets()`、`TakeAllWidgets()`、`Count()`、`ItemAt(index)`、`TakeAt(index)`、`SetAnimation(duration int)`、`SetVerticalSpacing/SetHorizontalSpacing(int)`。
- **效果**：控件从左到右依次排布，一行放不下时自动折到下一行；启用 `needAni` 后控件增减/尺寸变化时平滑移动。

### `AdaptiveFlowLayout`
- **功能**：自适应流式布局，在 `FlowLayout` 基础上把每行卡片拉伸为均匀宽度，并根据最小/最大卡片宽度自动计算每行数量。
- **构造**：`NewAdaptiveFlowLayout(parent *qt.QWidget, needAni, isTight bool)`。
- **关键方法**：`SetWidgetMinimumWidth(int)` / `WidgetMinimumWidth()`、`SetWidgetMaximumWidth(int)` / `WidgetMaximumWidth()`；继承 `FlowLayout`。
- **效果**：每行卡片宽度相同并填满可用宽度；容器变宽时每行容纳更多卡片，变窄时减少并自动折行。

## v_box_layout.go

### `VBoxLayout`
- **功能**：`QVBoxLayout` 的轻量封装，垂直堆叠控件，并额外记录所有加入的控件以便批量移除或删除。
- **构造**：`NewVBoxLayout(parent *qt.QWidget)`。
- **关键方法**：`AddWidget(widget, stretch int, alignment qt.AlignmentFlag)`、`AddWidgets([]*qt.QWidget, stretch, alignment)`、`RemoveWidget(widget)`、`DeleteWidget(widget)`、`RemoveAllWidgets()`。
- **效果**：控件按加入顺序从上到下垂直排列；`stretch` 控制控件获得额外空间的份额，`alignment` 控制对齐方式。

## expand_layout.go

### `ExpandLayout`
- **功能**：仅垂直方向的布局，把子控件按自然高度从上到下堆叠，并在父控件几何尺寸或子控件高度变化时自动重新布局。
- **构造**：`NewExpandLayout(parent *qt.QWidget)`。
- **关键方法**：`AddWidget(widget)`、`AddItem(item)`、`Count()`、`ItemAt(index)`、`WidgetAt(index) *qt.QWidget`、`TakeAt(index)`。
- **效果**：子控件按自然高度垂直堆叠；某个子控件（如可展开设置卡片）高度变化时，布局同步调整父控件高度，把后续内容向下推动。
